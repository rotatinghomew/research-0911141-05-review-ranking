# 短时复核路径

环境准备和镜像构建在操作前完成。服务的健康入口是 `/health`；服务启动即继续，不固定等待。若90秒内没有就绪，应停止操作并保留错误，不把等待算作成功运行。

从首页选择一个展示分组，先阅读“综合排序”上方的可比性横幅：若存在多个互不连通的评审组，跨组项目没有共同参照，全局名次只在标尺一致的假设下成立，应优先看组内名次、95% 区间与重叠带。点击任意项目行，可在“记录与依据”中核对各标准贡献、原始评分格、共同评委/桥接链和稳定性数据；点击评委行可核对严宽效应、原始均分与收缩比例。

调整某项标准权重或切换利益冲突回避后，点击“按当前配置重新计算”，观察名次区间和候选名单入选率如何变化，而不是只看点名次。需要比较两次决定时，先“把当前结果存为对照情景”，再改权重或追加手动回避并重新计算，情景表会逐行标出上升、下降与持平。存在利益关系的项目—评委对可在左侧“额外回避”中加入清单，生效的回避会在排序说明中列出。

输入会议名称并“冻结保存当前排序与依据”，页面随即进入冻结态：权重、回避和范围控件锁定，原始记录核对与导出仍可用。切换范围或重新计算需先“返回实时视图”。保存后再调整权重或导入数据，左侧历史材料中的名次与配置保持不变，可随时打开复核，最后导出当前记录。整段交互通常需要60至90秒，不依赖远程请求。

`fixtures/data.json` 可用于重新导入核对。页面说明的是观测和适用范围；不要为了演示修改数据以制造某种优胜、显著性或异常结论。新增加的分析也应从真实可用证据解释结果，不要求出现某个指定方向。统计口径的完整定义见 `docs/ranking.md`。

# 综合排序口径

本文件定义评审台“综合排序”功能的统计口径，`review_ranking/ranking.py` 的常量与本文件一致。目标是把交叉评审关系变成可复核的证据，而不是对有分格子直接求平均后给出看似精确的名次。

## 1. 评分格的四种状态

同一条评分记录只有一个状态，含义不同，不能互相折算：

- `scored`：有效打分，是唯一进入校准模型的格子。
- `abstain`：评委明确弃权，表示放弃评价，不是低分，不按零分处理。
- `invalid`：评分被撤销或判为无效，同样不进入模型，但在覆盖统计中单列。
- 缺记录（没有这一行）：该项目—评委—标准组合根本没有评审，与弃权和无效都不同。

`conflicts` 中的利益关系默认要求回避；主席也可以在页面上追加手动回避。被回避的 `scored` 格子不参与模型，但原始记录仍可通过“查看原始记录”核对。每个项目分别报告弃权格、无效格、回避格和缺席评委数。

## 2. 连通组与可比性

把项目和评委看作二部图，一条有效评分就是一条边。并查集得到的连通组有如下含义：

- 同一连通组内的任意两个项目，要么共享评委，要么可以经由“项目 A—评委—项目 B—评委—…”的桥接间接比较；页面给出共同评委清单或最短桥接链。
- 不同连通组之间没有共同参照，不存在把两边标尺对齐的统计依据。

跨组项目仍会显示一个“全局假设名次”，并以 `*` 与横幅显式标注：它只有在“各组评委标尺一致”的额外假设下才成立。主席应优先使用组内名次、95% 区间和重叠带。演示数据天然包含 4 个互不连通的评审组，单个展示分组内也可能不连通。

## 3. 加性校准模型

在每个连通组、每个评分标准上拟合

```
y(项目 i, 评委 j, 标准 c) = μ_c + a_i(c) + b_j(c) + ε
```

- `μ_c` 是该标准在组内的总体均值；`a_i(c)` 是项目效应，`b_j(c)` 是评委严宽效应。
- 两个效应各自均值约束为零，因此正的 `b` 代表该评委整体偏松（同样的项目给出更高分），负的代表偏紧。
- 评委效应使用岭收缩：估计值乘以 `n / (n + 3)`，先验强度 `RIDGE_PRIOR = 3` 个评分格。只有几个格子的评委不会被极端化，收缩比例在评委表中公开。
- 项目效应不收缩；证据不足通过标准误、可靠性标签和稳定性区间体现。
- 拟合用坐标下降，收敛阈值 `1e-9`、上限 200 次迭代。单项目连通组中项目效应与评委效应不可分离，此时约束项目效应为零，评委效应相对总体均值做岭估计，这是唯一可识别的口径。
- 节点身份依据数据中的项目表和评委表判定，不依赖编号字符串前缀。

项目在某标准上的校准分是 `μ_c + a_i(c)`；若该标准一个有效格都没有，则以该标准全局均值填补，标准误取全局残差标准差，并在贡献明细中把该标准标为 `imputed`，同时在标准表中统计被填补的项目数。

## 4. 综合分、标准误与重叠带

- 每个标准先折算到 0–1 标度（校准分除以满分），再按主席权重加权求和；权重允许为零，提交后自动归一化，至少一项必须为正。
- 综合分标准误在各标准残差独立的假设下按权重平方和传播，展示 95% 区间（`1.96 × SE`，截断到 [0,1]）。
- 组内按综合分排序，并生成“重叠带”：区间互相重叠的项目落在同一带内，同带项目不应被解读为确定的先后。
- 项目可靠性：有效评委少于 2 位为“证据不足”；少于 3 位或存在标准级缺测为“证据有限”；否则为“证据充分”。

## 5. 稳定性与候选名单

单次点名次不可靠，因此报告两类确定性的重采样结果（固定随机种子 `20261114`，可重复）：

- 权重扰动：40 次 Dirichlet 式指数权重抽样，报告每个项目的名次最小值、最大值、众数，以及进入前 `top_k` 候选名单的频率。
- 留一评委折刀：逐位移除评委后重新拟合连通组与模型，报告名次区间、候选名单入选率，以及该项目被移到无法估计的次数（`eliminations`）。

页面提供“对照情景”：主席先把当前结果存为快照，再调整权重或回避重新计算，表格逐行给出全局名次变化，避免拖动一次滑块就把某个项目固定成第一名。

## 6. 冻结保存

保存（notebook）在服务端按当时的选择条件和排序配置重新计算，结果整体写入 SQLite，客户端无法伪造。已保存材料包含原始数据版本指纹、范围、规范化后的权重与回避清单、完整排序与依据。后续导入新数据、调整权重或追加任何评语都不会改变已有材料；页面打开保存材料时进入冻结态，仅允许只读核对（原始记录、导出），恢复调整需显式“返回实时视图”。
